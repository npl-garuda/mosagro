# Карта сайта (этап 0)

Статус: зафиксировано. Прототип и тексты - **согласованы**.

## Публичные страницы

| URL | Назначение |
| --- | --- |
| `/` | Главная (без баннеров; блоки: оффер, для кого, как начать, категории, эксклюзив, новинки, бренды-партнёры) |
| `/about` | О компании |
| `/catalog` | Каталог (категории / все товары) |
| `/catalog/{category}` | Категория (в т.ч. «Новинки») |
| `/catalog/{category}/{product}` | Карточка товара (category = primary) |
| `/exclusive` | Эксклюзив (товары с `is_exclusive`) |
| `/documents` | Документы (общие разделы) |
| `/documents/{section}` | Раздел документов |
| `/price` | Запросить прайс лист |
| `/contacts` | Контакты (карта, email, адреса; без телефонов) |
| `/privacy` | Политика ПДн (заглушка) |
| `/consent` | Согласие на обработку ПДн (заглушка) |
| `/requisites` | Реквизиты |

## Служебные состояния

- Успех заявки на прайс: `/price/thanks` или состояние на `/price`
- Старые адреса `/cart`, `/checkout`, `/login`, `/cabinet` редиректим на `/price`

## Админка

| URL | Назначение |
| --- | --- |
| `/admin` | Filament - полный CRUD товаров и связанных сущностей |

## Примечания для прототипа / дизайна

- Тон текстов: сад / ферма / урожай + опт (как главная и «О компании»). Источник: `docs/copy.md`.
- На главной **нет** баннеров и промо-карусели; при дизайне - один hero-визуал.
- Один сценарий: «Запросить прайс лист».
- В карточке товара: название, бренд, короткое описание, фото (плейсхолдер), состав, применение, фасовки (справочно), документы; бейджи «Новинка» / «Эксклюзив».
- Документы: в карточке товара и отдельными общими разделами.
- «Новинки»: отдельная категория + бейдж по флагу.
- «Эксклюзив»: отдельная витрина; те же товары могут быть в общем каталоге.
- Блок «Бренды-партнёры» (логотипы).
- Демо-карточки в прототипе; полный каталог - от заказчика отдельно.
- Телефонов компании нет. Email и формы заявок - да. Телефон посетителя в формах - да.
- Админку дизайнеру не отрисовывать (Filament).
