# Карта сайта

Статус: актуально под `design_v3/` (2026-10-20).

## Публичные страницы

| URL | Назначение |
| --- | --- |
| `/` | Главная (без баннеров и без «Новинок»; оффер, о компании, преимущества, как начать, категории, эксклюзив, партнёры) |
| `/about` | О компании |
| `/catalog` | Каталог (все товары + фильтры + поиск) |
| `/catalog/{category}` | Категория (СЗР / от грызунов / HB-101 (Flora) / Прочее) |
| `/catalog/{category}/{product}` | Карточка товара |
| `/exclusive` | Эксклюзив (товары с `is_exclusive`) |
| `/documents` | Документы (общие разделы) |
| `/documents/{section}` | Раздел документов |
| `/price` | Запросить прайс лист |
| `/dealer` | Стать дилером |
| `/contacts` | Контакты (карта, email, адрес; без телефонов компании) |
| `/privacy` | Политика ПДн |
| `/consent` | Согласие на обработку ПДн |
| `/requisites` | Реквизиты |

## Служебные состояния

- Успех заявки на прайс: `/price/thanks`
- Старые адреса `/cart`, `/checkout`, `/login`, `/cabinet` → редирект на `/price`

## Зафиксировано для дизайна / вёрстки

- Макеты: **`design_v3/desktop/`** + **`design_v3/mobile/`** (эталон после сверки chrome). Архив: `design_v2/`, `design_v2_mobile/`.
- Фоны: `design_v3/backgrounds/` (полноразмерные hero / exclusive).
- Тексты: `docs/copy.md`. Шрифт: Open Sans. Логотип: `docs/logo.png`.
- **Сейчас:** вёрстка desktop + адаптив одним проходом (этап 4).
- **Единообразие:** шапка, подвал и межблочные интервалы одинаковые на всём сайте (эталон - `design_v3/desktop/01-home.jpg`).
- **Картинки:** hero/декор из `design_v3/backgrounds/`; товары - «Фото скоро» до каталога.
- Шапка sticky: лого · О компании · Каталог · Документы · Контакты · CTA «Запросить прайс лист» (на mobile CTA прайса только в бургер-меню).
- Футер: лого · «Стать дилером» · email/адрес · навигация · Реквизиты · Политика ПДн · Согласие.
- На главной нет trust-полоски и нет блока «Новинки»; партнёры без заголовка (на mobile нет).
- В карточке вкладки: Описание · Применение · Документы (без «Логистика»).
- Каталог: поиск по названию; фильтры Все товары · СЗР · от грызунов · HB-101 (Flora) · Прочее.
- Хлебные крошки **над H1**: `/catalog` → Главная / Каталог; категория и карточка - с полным путём.
- Формы `/price` и `/dealer`: одинаковые поля; обязателен только телефон организации; без галочки ПДн на форме.
- Телефонов компании на сайте нет.
