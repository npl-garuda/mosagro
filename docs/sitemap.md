# Карта сайта

Статус: актуально под staging / `laravel/` (2026-10-22). Макеты: `design_v3/`.

## Публичные страницы

| URL | Назначение |
| --- | --- |
| `/` | Главная (оффер, о компании, преимущества, как начать, категории, эксклюзив, партнёры) |
| `/about` | О компании |
| `/catalog` | Каталог (все товары + фильтры + поиск) |
| `/catalog/{category}` | Категория (СЗР / от грызунов / Floora / Прочее и др. из админки) |
| `/catalog/{category}/{product}` | Карточка товара (галерея фото, вкладки Описание · Применение · Документы) |
| `/exclusive` | Эксклюзив - товары с основной категорией `floora` |
| `/documents` | Документы (разделы) |
| `/documents/{section}` | Раздел документов |
| `/price` | Запросить прайс лист |
| `/dealer` | Стать дилером |
| `/contacts` | Контакты (карта, email, адрес; без телефонов компании) |
| `/privacy` | Политика ПДн (текст заказчика) |
| `/consent` | Согласие на обработку ПДн (текст заказчика) |
| `/requisites` | Реквизиты + скачивание карточки организации (xls) |

## Служебные состояния

- Успех прайса: `/price/thanks` (только после POST; иначе редирект на `/price`)
- Успех дилера: `/dealer/thanks` (только после POST; иначе редирект на `/dealer`)
- Старые адреса `/cart`, `/checkout`, `/login`, `/cabinet` → 301 на `/price`

## Зафиксировано (витрина)

- Runtime: `laravel/` на staging. Эталон UI: `design_v3/` + `layout/`.
- Тексты: `docs/copy.md`. Шрифт: Open Sans. Логотип: `docs/logo.png` / `public/images/logo.png`.
- Шапка sticky: лого · О компании · Каталог · Документы · Контакты · CTA «Запросить прайс лист» (на mobile CTA прайса только в бургер-меню).
- Футер: лого · «Стать дилером» · email/адрес · навигация · Реквизиты · Политика ПДн · Согласие.
- На главной нет trust-полоски и нет блока «Новинки»; партнёры без заголовка (на mobile нет); логотипы партнёров пока hardcoded.
- Бейджи «Новинка» / «Эксклюзив» - только флаги товара; `/exclusive` = primary category `floora`; CTA каталога → `/catalog/floora`.
- Каталог: живой поиск по названию; фильтры по активным категориям.
- Хлебные крошки над H1.
- Формы `/price` и `/dealer`: одинаковые поля; обязателен только телефон; без галочки ПДн на форме.
- Телефонов компании на сайте нет (в т.ч. в xls реквизитов).
